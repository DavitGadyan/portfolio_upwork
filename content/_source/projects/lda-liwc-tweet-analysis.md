## Hugo body

Goal of the project was to conduct LDA and LIWC analysis on Trump's tweets regarding Covid and few other topics.

#### Project Details

After initial EDA analysis and some text preprocessing, I have conducted LDA analysis using python tools such as pyLDAvis. As an output, we have interactive html formated files to look into clusters discovered by LDA algorithm. Using LIWC2015 Dictionary.dic I have conducted LIWC analysis in Python although initially there were some problems with encoded files we managed to contact the author of the work and he sent decoded version so many thanks to Dr. James W. Pennebaker.
