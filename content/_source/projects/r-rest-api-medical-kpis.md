## Hugo body

Project goals were to develop and integrate R script into existing Vue.js application for medical expert testing system.

#### Project Details

I have creared REST API using R programming language to put into production algorithm developed to calculate KPIs for CTE Medical Image Experts.

Based on client specifications and instructions various interactive graphs were developed using R Plotly framework for the user of the main application. Project involved 3 concescutive contracts with each contract concentrating on the improvement of the current and development of new features. End result was really what client looked for and together we had mutually beneficial cooperation.
